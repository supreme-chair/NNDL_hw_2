Deployment to GitHub Pages

To deploy this app:

  1. Create a new public repository on GitHub
  2. Commit both index.html and app.js files to the repository
  3. Go to repository Settings → Pages
  4. Set source to "Deploy from a branch", select "main" branch and "/ (root)" folder
  5. Click Save, then wait a few minutes for the site to be published
  6. Your app will be available at: https://[your-username].github.io/[repository-name]/

Note: This is a static site - no server is needed. All processing happens in the browser.
